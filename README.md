# DailyPlanHub

A simple and efficient **web-based study planner** to help students organize tasks, manage schedules, and stay focused on their academic goals.

---

##  Features

*  **Home Dashboard** – Overview of tasks and study progress
*  **To-Do Manager** – Add, update, and delete daily tasks
*  **Timeline / Schedule Planner** – Plan study sessions effectively
*  **Weekly Timetable** – Maintain a structured weekly routine
*  **Resource Links Organizer** – Save and access study materials
*  **Goals Tracker** – Set and track learning goals
*  **Focus Timer** – Improve productivity (Pomodoro-style)
*  **Stopwatch** – Track total study time
*  **Settings** – Customize your experience

---

2. Open the folder
3. Double-click `index.html` or open it in a browser

---

## 📌 Important Note

This is a **static web application**:

* Data is stored in **browser local storage**
* No backend/database is used
* Data will not sync across devices
